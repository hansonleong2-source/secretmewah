# secretmewah

A responsive, static social media website inspired by modern social platforms.

## Run locally

Just open `index.html` in your browser.

## Deploy to GitHub Pages

1. Create a new GitHub repository, for example `secretmewah`.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
5. Save and wait for GitHub to publish the website.

## Included

- Responsive desktop/mobile layout
- Home feed
- Create posts
- Like, comment, share, bookmark interactions
- Search
- Explore gallery
- Messages and notifications screens
- Profile screen
- Settings screen
- Dark mode
- Browser localStorage persistence

This is a frontend-only demo. For real accounts, cross-device posts, real-time chat, and cloud storage, connect a backend such as Supabase or Firebase.
